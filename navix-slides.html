Architecture June 2026 05 / 08
How it's built

Three layers.
Zero compromise.

Frontend
Vite · React · TypeScript
  • React Three Fiber — 3D star map
  • physics.ts — Rindler equations, client-side
  • Zustand — simulation state
  • Recharts — velocity & time charts
  • Tailwind CSS v4
Backend
FastAPI · Python
  • GET /api/stars/famous
  • GET /api/stars/nearby
  • GET /api/stars/search
  • GET /api/stars/:id
  • GET /health
Database
Supabase Postgres
  • 119,629 HYG v3.8 stars
  • pg_trgm GIN index — fuzzy search
  • Serverless pooler (port 6543)
  • x/y/z parsec coords per star
